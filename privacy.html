개인정보처리방침

본 방침은 랜덤 추천 사이트에서 처리하는 정보의 범위와 목적을 설명합니다.

1. 수집 정보

서비스 이용 시 처리되는 정보

기본 기능(로또 번호, 할 일/공부/음식 추천)은 사용자 로그인 없이 이용할 수 있으며, 해당 기능 자체를 위해 이름, 전화번호 같은 직접 식별 정보를 별도로 수집하지 않습니다.

제휴 문의 페이지를 통해 사용자가 자발적으로 제출한 이름, 이메일, 회사명, 문의 내용은 문의 대응을 위해서만 처리됩니다.

2. 동물상 분석 이미지 처리

브라우저 내 처리

동물상 분석 기능에서 업로드한 이미지 파일은 브라우저 메모리에서 분석에 사용되며, 운영 서버에 저장하지 않습니다. 분석 결과는 화면에 즉시 표시되며 별도 데이터베이스에 기록하지 않습니다.

3. 외부 서비스

댓글 및 광고

댓글 기능은 Disqus, 광고 기능은 Google AdSense를 사용합니다. 해당 외부 서비스는 각 서비스의 정책에 따라 쿠키 또는 접속 정보를 처리할 수 있습니다.

외부 서비스의 데이터 처리 방식은 각 사업자의 개인정보처리방침을 참고해 주세요.

4. 문의

개인정보 관련 문의

개인정보 처리 관련 요청은 문의 페이지로 보내주시면 확인 후 안내드리겠습니다.
